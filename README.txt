CLEAN OODI WEBSITE
==================

Files:
- index.html       Home page
- causes.html      Causes of poor waste management
- impact.html      Environmental and community impacts
- solutions.html   Practical waste-disposal solutions
- contact.html     Contact information and demo contact form
- style.css        Shared responsive styling
- images/          Image crops taken from the supplied design reference

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the clean_oodi_website folder.
3. Double-click index.html, or open the folder in Sublime Text.
4. Keep all HTML pages, style.css, and the images folder together.

EDITING:
- Shared colours, layout and responsive styles are in style.css.
- Update the sample email and phone number in contact.html before publishing.
- The contact form is a front-end demo and does not send messages without a backend/form service.
- Image crops come from the provided reference screenshot; replace them with original high-resolution photos for a production website.
